## 项目简介

InkVision 是一个基于 **Qt + C++ + OpenCV + ONNX + FastAPI + SQLite** 构建的智能手写识别项目。

项目最初的目标是完成一个本地运行的手写数字识别桌面应用：  
用户在画板中输入数字，程序完成图像预处理、ONNX 模型推理，并实时显示预测结果和各类别概率。

在此基础上，项目继续扩展，逐步形成了一套更完整的系统能力：

- **单数字手写识别**
- **手写表达式识别与求解**
- **客户端与服务端解耦**
- **异常样本上报与存储**
- **基于大模型的错误原因分析**
- **识别结果、反馈信息、分析结论的结构化管理**

## 核心功能

### 1. 手写数字识别
- 支持用户在桌面画板中手写输入数字
- 对画布内容进行图像预处理
- 使用本地 ONNX 模型完成推理
- 实时显示：
  - 预测类别
  - 预测置信度
  - 各类别概率柱状图

### 2. 手写表达式识别与求解
- 将画板内容转为图片后发送至服务端
- 服务端结合视觉识别结果与大模型能力进行表达式理解
- 返回标准表达式及其计算结果
- 支持将“手写内容识别”扩展为“识别 + 解释 + 求解”的完整链路

### 3. 本地推理与云端能力结合
- **本地端**负责：
  - 手写输入
  - 图像预处理
  - 数字分类推理
  - 可视化展示
- **服务端**负责：
  - 表达式识别接口
  - 异常反馈处理
  - 数据库存储
  - 大模型分析任务

这种设计使系统既保留了本地响应速度，也具备进一步扩展智能能力的空间。

### 4. 异常数据反馈系统
- 用户可将误识别样本或异常结果主动提交
- 反馈信息包含：
  - 手写图像
  - 使用模型
  - 预测结果
  - 置信度
- 服务端接收后写入数据库，形成可追踪的错误样本记录

### 5. AI 错误分析
- 服务端在接收到异常样本后，结合反馈信息构造提示词
- 调用大模型对错误原因进行分析
- 自动生成结果分析内容并存储到数据库
- 前端可进一步展示分析结果，用于帮助理解识别失败的原因

### 6. 数据持久化管理
- 通过 **MySQL** 存储识别异常反馈与分析结果
- 实现错误样本与分析结论的结构化留存
- 为后续的数据统计、样本回流、模型改进提供基础

## 项目架构

```text
用户手写输入
    ↓
Qt DrawBoard 采集画布内容
    ↓
[本地路径]
图像预处理 → ONNX 模型推理 → 预测结果/概率显示

    或

[服务端路径]
图片上传 → FastAPI 接口处理
          ├─ 表达式识别与求解
          └─ 异常样本反馈
                ↓
             MySQL 存储
                ↓
          大模型生成错误分析
                ↓
             返回前端展示
```

## 典型使用流程

### 数字识别流程

1. 用户在画板上手写数字
2. 系统进行图像预处理
3. 本地 ONNX 模型执行推理
4. 界面显示预测数字、置信度和类别概率

### 表达式识别流程

1. 用户在画板上书写表达式
2. 前端将图像发送到服务端
3. 服务端调用识别与理解逻辑
4. 返回表达式及计算结果
5. 前端展示识别结果

### 异常反馈流程

1. 用户发现识别错误
2. 提交当前图像、模型、结果、置信度
3. 服务端写入 MySQL
4. 服务端调用大模型进行错误分析
5. 分析结果保存并返回前端
